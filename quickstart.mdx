Let's make your first three API calls together: create a project, add a task to it, and list the tasks. Step by step, no rush. 🚀

## What you need

- Your API key
- A terminal with `curl`, or an API client like Postman

<Info>
The first request can take up to 60 seconds if the server was idle. Wait for it, this is normal. The next requests respond in under a second.
</Info>

## Step 1: Create a project

In TaskFlow, every task lives inside a project. So the first call is always this one:

```bash
curl https://test-writechoice.onrender.com/projects \
  -X POST \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "My first project", "description": "Testing the TaskFlow API"}'
```

The API answers with `201 Created` and returns your new project:

```json
{
  "project_id": "15978c3f-e860-4372-b268-22be0fdabcda",
  "name": "My first project",
  "description": "Testing the TaskFlow API",
  "created_at": "2026-07-31T00:24:11.756Z"
}
```

📌 Copy the `project_id` from your response. You will need it in the next step.

## Step 2: Create a task

Now use your `project_id` to add a task inside the project:

```bash
curl https://test-writechoice.onrender.com/tasks \
  -X POST \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"project_id": "YOUR_PROJECT_ID", "title": "My first task", "description": "Trying out the API"}'
```

The API answers with `201 Created`. Notice the `status` field: every new task starts as `pending`, even if you don't send a status:

```json
{
  "task_id": "3272f799-9728-42f9-98ad-f99c8d21128d",
  "project_id": "15978c3f-e860-4372-b268-22be0fdabcda",
  "title": "My first task",
  "description": "Trying out the API",
  "status": "pending",
  "created_at": "2026-07-31T00:25:32.624Z",
  "updated_at": "2026-07-31T00:25:32.624Z"
}
```

## Step 3: List your tasks

Time to confirm everything worked. One detail here: the `project_id` goes in the URL, not in the body.

```bash
curl https://test-writechoice.onrender.com/projects/YOUR_PROJECT_ID/tasks \
  -H "Authorization: Bearer YOUR_API_KEY"
```

The API answers with `200 OK` and your list of tasks:

```json
{
  "project_id": "15978c3f-e860-4372-b268-22be0fdabcda",
  "total": 1,
  "tasks": [
    {
      "task_id": "3272f799-9728-42f9-98ad-f99c8d21128d",
      "project_id": "15978c3f-e860-4372-b268-22be0fdabcda",
      "title": "My first task",
      "description": "Trying out the API",
      "status": "pending",
      "created_at": "2026-07-31T00:25:32.624Z",
      "updated_at": "2026-07-31T00:25:32.624Z"
    }
  ]
}
```

That's it! 🎉 You created a project, added a task, and listed it back. These three calls are the heart of TaskFlow.
