# TaskFlow API Documentation 📚

Public documentation for **TaskFlow**, a simple task management API. Built with [Mintlify](https://mintlify.com) for the WriteChoice technical writing test.

**Live site:** https://gabrielacunha.mintlify.site

## What's inside

| File | What it is |
| ---- | ---------- |
| `index.mdx` | Introduction: what the API is and how it works |
| `authentication.mdx` | How to authenticate every request |
| `quickstart.mdx` | Your first three API calls, step by step |
| `workflow.mdx` | The full task lifecycle: update and delete |
| `troubleshooting.mdx` | Common errors (400, 401, 404) and how to fix them |
| `faq.mdx` | Quick answers to common questions |
| `openapi.yaml` | The API spec that generates the API Reference pages |
| `docs.json` | Site configuration and navigation |

## How it was made

Every endpoint was tested against the live API before writing. All example responses in the docs are real responses from those tests, including the error messages in the Troubleshooting page.
