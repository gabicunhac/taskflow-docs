## What is TaskFlow? 🚀

TaskFlow is a REST API for task management. With it, you can create projects, add tasks inside them, update the status of each task, and delete tasks you no longer need.

Think of TaskFlow as the engine behind a to-do app: it stores and organizes your data, and you decide how to use it.

## How it works

TaskFlow has only two resources: **projects** and **tasks**. Every task lives inside a project. Because of that, the API follows a clear order:

1. First, create a project and save its `project_id`
2. Then, create tasks inside that project using the `project_id`
3. Now you can list, update, or delete tasks using their `task_id`

💡 If you skip a step, the API returns an error. For example: if you try to create a task with a `project_id` that does not exist, you get a `404 Not Found`.

## Available endpoints

The API has five endpoints. Here is the full map:

| Method | Endpoint | What it does |
| ------ | -------- | ------------ |
| POST | `/projects` | Create a project |
| POST | `/tasks` | Create a task inside a project |
| GET | `/projects/{project_id}/tasks` | List all tasks in a project |
| PATCH | `/tasks/{task_id}` | Update a task |
| DELETE | `/tasks/{task_id}` | Delete a task |

## Task lifecycle

Every new task starts with the status `pending`. From there, you can move it forward using the update endpoint:

`pending` → `in_progress` → `done`
